## 날짜별 진행

### 11월 10일: 서버 열기와 RPG 뼈대

- "스텔라이브 서버 같은 마크 서버"를 목표로 Paper 서버를 깔고 EULA 동의 후 첫 실행.
- 화이트리스트, EssentialsX(집·텔포·경제), LuckPerms(권한), Simple Voice Chat(근거리 음성).
- RPG 요소: 상점, 스탯, 탈것, 커스텀 아이템. 탈것은 커스텀 동물로, 확률로 잡는 **그물총**.
- 보스: 오크 부족, 드래곤, 그리스 신화 몹(사이렌, 메두사, 미노타우로스, 키클롭스, 하피, 케르베로스).
- BetterModel을 깔고 모든 몹 모델을 파이썬으로 직접 생성. 사이렌 얼굴·꼬리·창, 메두사 얼굴, 용 눈 표정을 여러 번 다듬음.
- 펫: 받은 스킨 6장으로 아군 펫 제작. 총·검 무기와 공격 동작, 전투에 들어가면 복장이 바뀌는 펫(린 → 리코, 라피).
- 펫 뽑기(가챠): 꽝(철 5개·다이아 1개)이 대부분, 펫 총합 4%, 40회 천장.
- playit.gg로 바깥 접속, 리소스팩 공개 호스팅, `.command` 실행 파일.
- 환장 RPG 느낌으로 직업·스킬·퀘스트 확장. 직업 선택 화면 한글화, 스폰에 NPC 배치.
- 탈것 정리: 드래곤·페가수스·그리핀·워그 탈것 삭제, 별빛 고래·마법 빗자루 같은 나는 탈것 추가.

### 11월 11일: 맵, 등급, 메뉴

- 펫 무기 확정: 라피 개틀링건, 스노우화이트 저격총, 엘리스 권총, 신데렐라 기계 방패(원거리).
- 그리스 신화 몹이 무기를 자연스럽게 쥐도록 손 위치 수정.
- 7000x7000 RPG 맵 적용.
- 장비 등급: 일반, 레어, 유니크, 고대, 영웅, 전설, 초월, 신화.
- 명령어 대부분 한국어로 쓸 수 있게 별칭 정리(`commands.yml`).
- 생활 직업 탈퇴 금지, **Shift+F 메뉴**, 우클릭·좌클릭·쉬프트 조합 스킬.
- 장식 탈것: 바닐라 말·늑대·여우 위에 왕관·망토만 얹기(새로 모델링하지 않음).
- 비룡 탈것 모델링, 그물 포획 확률을 등급별로 나눔.
- BetterModel 기본 예제 모델(데몬 나이트, 푸른 대마법사)을 보스로 사용.

### 11월 12일: Skript 콘텐츠, 대장간, 입체 무기

- 상점 한국어화, 구매 가격 10배(인챈트 30배), 상점 수 줄이기.
- Skript로 레벨·능력치·일일 의뢰·던전·몬스터 스폰 조건 제작. 던전은 Shift+F 메뉴에서 입장.
- 새 맵(Domae) 적용, GUI 꾸미기(리소스팩 배경 그림), 직업마다 다른 능력치 성장, 이름 꾸미기.
- 퀘스트에 ! 표시, 연계 퀘스트, 폭발 방어.
- 리소스팩 호스팅 이동: catbox → 0x0.st(업로드 막힘) → **구글 드라이브**.
- playit 24시간 운영 + 열·배터리 절약 설정, 레드스톤·공장 아이템 금지.
- 무기·방어구 추가 능력치, **입체 무기**(Armourer's Workshop처럼 블록을 쌓은 모델)를 다섯 번 넘게 다듬음.
- 검·활·지팡이 종류마다 다른 모양, 9번 검은 대검, 암살자 단검, 달·해·해골 지팡이, 고서 5권(5번째는 저주받은 책), 방어구 고해상도 무늬.
- 히든 퀘스트 7개(낚시·점프맵·노가다·농사·광질·몬스터), 숨긴 NPC, 이그니스 랜덤박스, 50층 파쿠르 탑.
- 이그니스를 서양 드래곤으로 바꾸고 눈을 더 무섭게, 다른 보스 모델 품질 끌어올리기.

### 11월 13일: 탈것·펫 다듬기, 흑룡, 도감, 깃허브

- 보스가 든 무기 7종(도끼·큰도끼·양날도끼·활·지팡이·몽둥이·삼지창) 세밀화.
- 비룡 탈것: 서양 용 → 청룡 → **흑룡**(S자 목, 똬리 몸통, 불꽃 갈기, 짧게 접은 다리, 금빛 찢어진 눈).
- 별빛 고래·마법 빗자루·펫 무기 장식 추가.
- 게임 안 **GUI 도감**(`/도감`, 누르면 3D 모델이 앞에 나타남)과 `/장비도감`.
- HTML 도감과 명령어 안내 페이지, `/명령어` 도움말 재정리.
- 깃허브 저장소에 소스·사이트·대화 기록 업로드, 저장소 공개 후 GitHub Pages 개설.
- 방어구 40종 입체 모델, 도감 뷰어의 바닥 판(숨김 요소·스킬 효과) 제거와 캐시 문제 해결.
- 흑기사 기마 보스 추가, 펫 이름 바로잡기(세컨드 → 린, 수영복 → 라피).
- 렉 때문에 서버 종료.

### 11월 14일~16일: 흑기사 다시 만들기, 정리

- 흑기사 모델을 질감 그림(판금·말털·천)과 새 모양으로 다시 제작, 서버를 잠깐 켜서 리소스팩 v19 배포 후 다시 끔.
- 그림 속 말 탄 기사를 bettermodel jar와 BetterModel 깃허브에서 찾았지만 없음. jar의 steve 모델과 저장소의 테스트용 knight 모델을 꺼내 둠.
- 이 작업 기록 작성.

## 서버와 호스팅

| 파일 | 하는 일 |
| --- | --- |
| `server/tools/start.sh` | Java 실행 옵션. `nice -n 10`(낮은 우선순위), 메모리 2~5GB, CPU 6코어 제한, G1GC 튜닝 |
| `server/tools/run-server.sh` | launchd가 부르는 실행 스크립트. 이미 켜져 있으면 다시 켜지 않음 |
| `server/tools/서버켜기.command` | 더블클릭으로 서버와 playit 켜기 |
| `server/config/commands.yml` | 한국어 명령어 별칭 (`/집`=`/home`, `/귓`=`/msg`, `/판매`=`/sellall` 등) |

- **24시간 운영**: `~/Library/LaunchAgents`에 세 가지를 등록했어요.
  - `com.starserver.minecraft`: 서버. 비정상 종료 때만 다시 켬(`KeepAlive SuccessfulExit=false`). `stop`으로 끄면 다시 켜지지 않아요.
  - `com.starserver.playit`: 바깥 접속 터널.
  - `com.starserver.awake`: `caffeinate -s`로 맥이 잠들지 않게 함.
- **서버 조작**: 콘솔 명령은 `console.in` 파일에 한 줄 쓰면 들어가고, 로그는 `server.out`에 쌓여요.
- **playit 비밀키**는 깃허브에 올리지 않았어요.

## MythicMobs 몹과 보스

`server/mythicmobs/`에 있어요. 몹마다 `model{mid=...}`로 BetterModel 모델을 붙여요.

- **오크부족.yml**: 오크 전사·궁수·주술사, 오크 대족장 크루가, 적룡 이그니스(`보스_적룡`).
- **그리스신화.yml**: 사이렌, 하피, 케르베로스, 키클롭스, 미노타우로스, 메두사.
- **마왕군.yml**: 데몬 나이트, 푸른 대마법사, **흑기사**(`보스_흑기사`, 말 탄 기사).
- **보스스킬.yml**: 보스 스킬. 흑기사는 찌르기·돌격(돌진 후 날려 버림)·창격(주변 피해와 둔화).

## 3D 모델 만들기

블록벤치로 손으로 만들지 않고, **파이썬 코드로 모델 파일(.bbmodel)을 생성**했어요. 그래서 "더 무섭게", "다리 줄여" 같은 요청을 코드를 고쳐 다시 만드는 식으로 반영했어요.

### `server/models-src/generate_models.py` (2,468줄)

- `Model` 클래스: 뼈대, 큐브, 16x16 픽셀아트(얼굴·비늘 등, 모델당 32장까지), 애니메이션(molang 식), 텍스처 자동 생성.
- `box()`: 바닥 기준 상자, `_seg()`·`_tube()`: 두 점을 잇는 회전 막대·굵기가 변하는 관(목·꼬리·몸통).
- 몬스터: `humanoid()`(오크·그리스 신화), `quadruped()`(케르베로스 등), `face_detail()`·`decorate()`(눈썹뼈·코·턱·견갑·팔찌), `texturize()`(색에 따라 금속·가죽·천·털 질감).
- 보스가 든 무기: 도끼·큰도끼·양날도끼·활·지팡이·몽둥이·삼지창을 날 끝 하이라이트·리벳·감개까지 세밀하게.
- 드래곤: `western_dragon()`(이그니스: 5마디 S자 목, 7마디 꼬리, 박쥐 날개, 무서운 눈 그림), `eastern_dragon()`(예전 동양 용).
- 흑룡: `black_dragon()`(S자 목, 똬리 몸통, 불꽃 갈기·등지느러미, 뒤로 휜 뿔, 긴 수염, 짧게 접은 다리, 금빛 찢어진 눈, 안장).
- 흑기사: `dark_rider()` + `_plate_rows()`·`_hide_rows()`·`_cloth_rows()`(판금·말털·천 질감 그림).

## 리소스팩 배포

1. BetterModel이 모델 팩(`build.zip`)을 만들고, `PackServer`가 `pack-extra`(입체 무기·방어구·GUI 그림)와 합쳐요.
2. `curl localhost:8163/pack.zip`으로 합친 팩을 만들고 해시를 계산해요.
3. 구글 드라이브 폴더에 새 버전으로 올리고, 다시 내려받아 해시가 같은지 확인해요.
4. `plugins/StarRPG/config.yml`의 `public-url`을 새 주소로 바꾸고 서버를 재시작해요.
5. `server/tools/pack-uploads.log`에 기록해요.

v2부터 v19까지 올렸어요. 서버가 켜질 때 팩 주소를 읽기 때문에 주소를 바꾸면 꼭 재시작해야 해요.

## 도감·명령어 사이트와 깃허브

- **도감** (`dex/`): three.js로 3D 모델을 돌려 보고 애니메이션을 재생해요. 보스·몬스터 14, 탈것 23, 펫 6, 장비 85. 히든 장비는 가려요.
- **명령어** (`commands/`): 명령어 78개를 분류별로 하는 일·쓰는 법·예시와 함께 정리하고 검색할 수 있어요.
- **게임 안**: `/도감` GUI, `/장비도감`, `/명령어`.
- **깃허브**: https://github.com/pink-light-star/mine (공개), GitHub Pages로 사이트 운영.
- 도감 데이터·썸네일 주소에 데이터 해시를 붙여, 바뀌면 브라우저가 새 파일을 받게 했어요.

## 문제와 해결

| 문제 | 원인 | 해결 |
| --- | --- | --- |
| launchd로 서버를 다시 켜도 안 켜짐 | 실행 스크립트의 중복 확인이 내 명령어 글자까지 잡음 | 다시 켜는 명령에 그 글자가 들어가지 않게 함 |
| 리소스팩 링크가 0바이트 | catbox 장애, 0x0.st 업로드 막힘, playit 무료는 HTTP 불가 | 구글 드라이브 폴더로 옮기고 직접 다운로드 주소 사용 |
| 입체 무기 일부가 안 만들어짐 | 스크립트 실행 블록이 파일 중간에 있어 뒤쪽 코드가 무시됨 | 실행 블록을 파일 끝으로 옮김 |
| 다른 스크립트를 불러오면 모델이 덮어써짐 | 불러오기만 해도 실행되는 코드 | `__main__` 보호 추가 |
| 고서 전체가 빛남 | 빛을 깊이로 판단 | 빛나는 색만 빛나게 |
| 이그니스 발·뿔이 떠 있음 | 위치·회전 기준점 오류 | 좌표와 기준점 수정 |
| 흑룡 눈이 4개처럼 보임 | 옆면 눈 그림과 정면 안광, 주황 콧구멍 | 정면 안광 제거, 콧구멍 어둡게 |
| 비룡 탈것의 날개 막이 사라짐 | 등가시를 지우는 조건이 날개까지 잡음 | 몸통 뼈의 큐브만 지우게 제한 |
| 도감에 바닥 판·찌그러진 판 | 외부 모델의 숨김 요소, 스킬 효과 그림, 텍스처 없는 면 | 그리지 않게 하고 데이터에 버전 붙이기 |
| 도감 3D가 안 보임(테스트 창) | 숨겨진 창에서 애니메이션 프레임이 멈춤 | 모델을 불러올 때 카메라를 바로 맞춤 |
| GitHub Pages 켜기 실패 | 무료 계정은 비공개 저장소에 Pages 불가 | 사용자 결정으로 저장소 공개 |
| 콘솔 `sk reload`가 엉뚱하게 동작 | `sk`가 AuraSkills 명령 | 서버 재시작으로 적용 |
