# 별빛 서버

한국어 마인크래프트 RPG 서버를 만든 기록이에요. 서버 프로그램과 직접 만든 플러그인, 스크립트, 3D 모델 생성기, 도감·명령어 사이트, 만들면서 나눈 대화를 모았어요.

## 사이트

GitHub Pages로 열려요.

- [첫 화면](index.html)
- [도감](dex/): 보스·몬스터 13종, 탈것 23종, 펫 6종, 장비 85종. 카드를 누르면 3D 모델을 돌려 보고 애니메이션을 재생해요.
- [명령어](commands/): 명령어 78개를 분류별로 정리했어요. 하는 일, 다른 이름, 쓰는 법, 예시가 있어요.

## 서버 구성

| 항목 | 내용 |
| --- | --- |
| 서버 | Paper 1.21.11, Java 25 |
| 직접 만든 플러그인 | StarRPG (Java): 직업·스킬·레벨, 퀘스트·히든 퀘스트, 펫 뽑기, 탈것 포획, 도감 GUI, 리소스팩 서버 |
| 스크립트 | Skript: 대장간(장비 84종), 능력치, 던전, 랜덤박스, 파쿠르 탑, 금지 아이템, 이름 꾸미기, 잡화점 |
| 몹 | MythicMobs + BetterModel: 오크 부족, 그리스 신화, 마왕군, 적룡 이그니스 |
| 그 밖의 플러그인 | EssentialsX, LuckPerms, EconomyShopGUI, Jobs, AuraSkills, EvenMoreFish, TAB, Simple Voice Chat |
| 접속 | playit.gg 터널, macOS launchd로 24시간 자동 실행 |

## 폴더

| 폴더 | 내용 |
| --- | --- |
| `dex/` | 도감 사이트 (3D 모델 데이터 `dex-data.json`, 썸네일) |
| `commands/` | 명령어 사이트 |
| `docs/대화기록.md` | 제작하면서 나눈 대화 (도구 출력·시스템 메시지는 빼고, 이메일 같은 개인정보는 가림) |
| `server/plugin-starrpg/` | StarRPG 플러그인 소스. `build.sh` 로 빌드 |
| `server/models-src/` | 3D 모델 생성기. `generate_models.py` 가 BetterModel 모델을, `forge/` 가 입체 무기·방어구를 만들어요. `build_dex.py` 는 도감 데이터를 만들어요 |
| `server/skript/` | Skript 스크립트 |
| `server/mythicmobs/` | 몹·스킬·아이템·드롭 설정 |
| `server/config/` | 한국어 명령어 별칭(`commands.yml`), StarRPG 설정 |
| `server/tools/` | 서버 실행·리소스팩 업로드·대화 기록 내보내기 스크립트 |

월드, 플레이어 데이터, 서버 jar, playit 접속 비밀키는 올리지 않았어요.

## 만든 것들

- **서버 열기**: Paper 서버, 화이트리스트, 한국어 명령어 별칭, playit.gg로 바깥 접속, launchd로 24시간 자동 실행. 열과 배터리를 줄이려고 낮은 우선순위로 돌려요.
- **RPG**: 전투 직업과 전직, 스킬(키 조작·MP·쿨타임), 레벨, 능력치(힘·민첩·지능·체력·행운), 칭호, 월드 퀘스트, 일일 의뢰.
- **퀘스트**: 마을 NPC 퀘스트와 히든 퀘스트 7개(낚시·점프맵·노가다·농사·광질·몬스터). 히든 NPC는 숨겨 뒀어요.
- **던전과 보스**: 웨이브 던전, 오크 대족장 크루가, 메두사, 미노타우로스, 데몬 나이트, 푸른 대마법사, 적룡 이그니스. 이그니스를 잡으면 랜덤박스가 나와요.
- **대장간**: 특수 무기 21종(검·대검·활·지팡이·단검·고서), 방어구 4세트, 6단계 기본 장비. 장비마다 요구 레벨·요구 능력치·추가 능력치가 있어요. 무기는 블록을 쌓은 입체 모델이에요.
- **펫과 탈것**: 펫 뽑기(전투 시 변신하는 펫 포함), 그물총으로 탈것 포획, 별빛 고래·마법 빗자루·신화 탈것 흑룡.
- **3D 모델**: 모든 보스·몬스터·탈것·펫 모델을 파이썬으로 생성. 서양 드래곤 이그니스, 흑룡, 보스가 든 무기까지 여러 번 다듬었어요.
- **파쿠르 탑**: 50층 탑 맵, 숨겨진 NPC와 대화하면 이동해요.
- **도감**: 게임 안 `/도감` GUI(누르면 3D 모델이 앞에 나타남), `/장비도감`, 그리고 이 사이트.
- **기타**: 레드스톤·공장 아이템 금지, 폭발 방어, 리소스팩 자동 병합과 구글 드라이브 배포.
